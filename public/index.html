About This Simple Node.js Server

This page is returned from a local HTML file.

My Node.js server reads this file from the filesystem and sends it when someone opens http://localhost:3000/.

There is no Express.js here — this is a pure, minimal HTTP server.

Features of this server:

  • Handles HTTP requests manually
  • Returns HTML files
  • Uses Node's built-in fs module
  • Supports further extension (static files, routing)
